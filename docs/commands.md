# Commands

Generated by `tools/gen_commands.py` from each tool's docstring; edit the docstring and rerun,
never this page. Run tools with the repository's venv (`.venv/Scripts/python` on Windows,
`.venv/bin/python` elsewhere). Setup order for a new clone: `docs/reference.md`,
"Rebuilding everything from scratch".

## Setup and the dump

### `tools/setup.py`

Copy a user-supplied ExeFS/RomFS dump into orig/<version>/ and verify it.

```sh
python tools/setup.py --version 2.1.0 --exefs <dir> --romfs <dir>
python tools/setup.py --version 2.1.0 --verify-only
```

### `tools/verify_dump.py`

Check orig/<version>/ against the game's own internal records.

```sh
python tools/verify_dump.py --version 2.1.0
```

### `tools/nso2elf.py`

Convert a Switch NSO into an ELF64 (AArch64, ET_DYN) that Ghidra and LLVM tools can read.

```sh
python tools/nso2elf.py orig/2.1.0/exefs/main orig/2.1.0/main.elf
```

### `tools/fetch_toolchains.py`

Download candidate upstream LLVM/Clang releases for compiler identification.

```sh
python tools/fetch_toolchains.py [VERSION or TOOL ...]   (default: LLVM candidates + objdiff)
python tools/fetch_toolchains.py glslang-16.6.0               (glslang, by name only)
python tools/fetch_toolchains.py vulkan-headers-1.4.328       (Vulkan headers, by name only)
python tools/fetch_toolchains.py llvm-mingw-20261006          (llvm-mingw, by name only)
```

### `tools/fetch_sources.py`

Download upstream third-party sources used to identify and build library code linked into the game, and the libc++ headers the build uses (open source only; see docs/references.md).

```sh
python tools/fetch_sources.py [NAME ...]   (default: all in SOURCES)
```

## Reconnaissance

### `tools/recon/run.py`

Binary reconnaissance that needs no Ghidra. Writes JSON to build/recon/<version>/.

```sh

```

### `tools/ghidra/analyze.py`

Import orig/<version>/main.elf into a Ghidra project, auto-analyse it, then export.

```sh
python tools/ghidra/analyze.py --version 2.1.0 [--module main] [--reanalyze]
```

### `tools/ghidra/export.py`

Export analysis results from the Ghidra project to build/ghidra_export/<version>/.

```sh
python tools/ghidra/export.py --version 2.1.0 [--module main]
```

### `tools/sigmatch.py`

### `tools/tu_map.py`

Recover main's translation-unit (TU) layout from .init_array, so new sources can be named and placed by the unit (class) they belong to instead of by address slice.

```sh
python tools/tu_map.py --version 2.1.0        # write data/tu_map.csv, print the sanity checks and layout statistics
python tools/tu_map.py --function 71003f13fc  # the unit of a function and its hint, for naming a file
python tools/tu_map.py --function CActor::refl_GetClass   # the same, by a data/functions name
python tools/tu_map.py --report               # coverage, confidence histogram, U functions per hint
python tools/tu_map.py --top 20               # the largest units
```

## Matching

### `tools/trymatch.py`

Build one source file with the project toolchain and diff it against the original.

```sh
python tools/trymatch.py --version 2.1.0 src/flag_id/fn_7100227448.cpp
python tools/trymatch.py --version 2.1.0 scratch.cpp -v              # side-by-side diff
python tools/trymatch.py --version 2.1.0 scratch.cpp -- -fno-inline  # extra compiler flags
```

### `tools/asmdiff.py`

Compare functions in a compiled AArch64 object file against the original binary.

```sh
python tools/asmdiff.py --version 2.1.0 build/obj/foo.o [-v] [--no-reloc]
```

### `tools/nearcopy.py`

```sh
python tools/nearcopy.py --version 2.1.0 --refs U O
```

## Checks and progress

### `tools/check.py`

Build every source in src/ with the project toolchain and check it against the original.

```sh
python tools/check.py --version 2.1.0            # report; exit 1 if an O function regressed or a function is defined in two files
python tools/check.py --version 2.1.0 --update   # also write O/m/M/W into data/functions/
python tools/check.py --version 2.1.0 --no-reloc # bytes only, as before the relocation check
python tools/check.py --compile-only             # compile every source, no dump needed (hosted CI)
```

### `tools/verify.py`

One-command gate: regenerate, check, report progress and the content rules, in a few lines.

```sh
python tools/verify.py --version 2.1.0 [--regen gen_statics,gen_clones]
```

### `tools/progress.py`

Whole-binary decompilation progress, from the status column of data/functions/.

```sh
python tools/progress.py [--json build/progress.json] [--top 15]
python tools/progress.py --slice boot [--version 2.1.0] [--json build/progress.json]
python tools/progress.py --slice boot --handoff
python tools/progress.py --slice-from CGameBlackboard::refl_GetClass
```

### `tools/policy_check.py`

Check tracked files against the content rules in CONTRIBUTING.md.

```sh
python tools/policy_check.py                 # every tracked file
```


## Refactoring (header migrations, file moves)

### `tools/hub_migrate.py`

Mechanical canonical-header migration of fn_/g_unk_ symbols, verified by tools/baseline.py.

```sh
python tools/hub_migrate.py --version 2.1.0 SYMBOL [SYMBOL...] [--header include/x.h [--declaration "..."]]
python tools/hub_migrate.py --version 2.1.0 --header-redeclared        # every symbol include/ declares once
python tools/hub_migrate.py --version 2.1.0 SYMBOL --dry-run             # show the edits, change nothing
python tools/hub_migrate.py --version 2.1.0 --plan PLAN.tsv [--generated-sample N] [--dry-run]
```

### `tools/baseline.py`

Snapshot and compare tools/trymatch.py output for a set of sources, in parallel.

```sh
python tools/baseline.py save    --tag T [FILE...] [@LIST] [--symbol SYM]... [--includers HDR]...
python tools/baseline.py compare --tag T [the same selection; default: every file saved under T]
python tools/baseline.py restore --tag T [FILE...]          # default: every file compare found changed
python tools/baseline.py files   [selection]                 # print the resolved file set
```

### `tools/unit_move.py`

Move hand-written sources out of the address-named directories into directories by unit.

```sh
python tools/unit_move.py            # the plan: counts and a sample of moves
python tools/unit_move.py --apply    # move with `git mv` and rewrite the includes
```

### `tools/objcompare.py`

Compare two trees of compiled objects function by function: code bytes and relocations.

```sh
python tools/objcompare.py build/units_before build/check/compile-only
```

## Port

### `tools/port_sweep.py`

Compile every source under src/ for a PC target (compile only) and report what does not port.

```sh
python tools/port_sweep.py --version 2.1.0                        # host clang++, x86_64-linux-gnu
python tools/port_sweep.py --version 2.1.0 --jobs 16 --json build/port/sweep.json
python tools/port_sweep.py --version 2.1.0 --only '^src/game_s7/'  # a subset while fixing one category
python tools/port_sweep.py --version 2.1.0 --no-runtime            # without port/runtime/include
python tools/port_sweep.py --version 2.1.0 --system-stdlib         # the host's own libc++/libc (Linux, macOS)
python tools/port_sweep.py --version 2.1.0 --target x86_64-w64-mingw32   # Windows, compile only (llvm-mingw)
```

### `tools/port_link.py`

Link every object of the port into one relocatable file and report what is missing.

```sh
python tools/port_link.py --version 2.1.0                      # build/port/sweep -> build/port/link
python tools/port_link.py --version 2.1.0 --objects build/port/sweep --out build/port/link
python tools/port_link.py --version 2.1.0 --cxx /usr/bin/clang++ --target x86_64-linux-gnu --system-stdlib
python tools/port_link.py --version 2.1.0 --alias-mismatch     # emit the class_mismatch aliases instead of traps
python tools/port_link.py --version 2.1.0 --no-libraries       # without lib/lua and lib/dlmalloc (the first M1 run)
python tools/port_link.py --version 2.1.0 --lifted build/port/lifted   # with tools/port_lift.py's semantic lifts
```

### `tools/port_lift.py`

Semantic lifts for the port: a source for every boot-slice function nobody has written yet.

```sh
python tools/port_lift.py --version 2.1.0                      # the boot slice (and the overrides) -> build/port/lifted/
python tools/port_lift.py --version 2.1.0 --slice all --out build/port/lifted_all   # every U function
python tools/port_lift.py --version 2.1.0 --top 200            # its first 200 entries (-> build/port/lifted_partial/)
python tools/port_lift.py --version 2.1.0 --only 710007fe68,7101047270 [-v]
```

### `tools/port_addresses.py`

Recover the original address of the symbols tools/port_link.py cannot place, from matched code.

```sh
python tools/port_addresses.py --version 2.1.0      # -> build/port/addresses.json (about a minute)
python tools/port_link.py --version 2.1.0           # then the link uses it
```
